# Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue.

Nutze stattdessen die private Meldung auf GitHub: im Repository unter **Security → Report a vulnerability** (GitHub Private Vulnerability Reporting). Beschreibe, was betroffen ist, wie sich die Lücke nachvollziehen lässt und welche Version oder welcher Commit betroffen ist.

Wir bestätigen den Eingang und melden uns mit einer Einschätzung. Bis eine Behebung veröffentlicht ist, bitten wir darum, Details vertraulich zu behandeln.

Das letzte Sicherheitsreview steht in [docs/11-sicherheitsreview.md](docs/11-sicherheitsreview.md).

## Unterstützte Versionen

Lenipo ist noch vor Version 1.0. Behebungen gibt es für den aktuellen Stand von `main`.
